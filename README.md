# Portfolio

A modern, responsive portfolio website built to showcase my profile, projects, skills, and educational background.

## Technologies Used

- **Framework:** React 19
- **Build Tool:** Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React & React Icons
- **Components:** Radix UI & Shadcn/UI
- **Animations:** Tw-Animate-CSS
